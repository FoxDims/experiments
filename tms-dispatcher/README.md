# SmartTransport — рабочее место диспетчера

Интерактивный прототип B2B-системы управления городским автобусным транспортом (Рязань).
Сценарий: поломка автобуса на маршруте № 10 и его замена резервным бортом.

## Как открыть

**С Яндекс Картами (основной вариант) — GitHub Pages:**

1. Settings → Pages → Source: *Deploy from a branch*, ветка `claude/tms-dispatcher-dashboard-nabx0j` (или `main` после слияния), папка `/ (root)`.
2. Прототип откроется по адресу `https://foxdims.github.io/experiments/tms-dispatcher/`.
3. В кабинете [developer.tech.yandex.ru](https://developer.tech.yandex.ru) у ключа JavaScript API
   укажите ограничение по HTTP Referer: `foxdims.github.io` и, для локальной работы, `localhost`.

Локально: `python3 -m http.server` в корне репозитория → `http://localhost:8000/tms-dispatcher/`.
С `file://` Яндекс Карты могут не загрузиться из-за проверки домена ключа.

Ключ лежит в `config.js`. Ключ JS API всегда виден в коде страницы, его защищает ограничение по доменам.

**Без Яндекс Карт.** Если API недоступен (нет ключа, домен не разрешён, страница открыта артефактом),
прототип сам переключается на собственную векторную схему Рязани.

## Карта

- Leaflet рисует данные: маршруты, автобусы, эффекты аварии, в той же проекции Web Mercator, что и JS API 3.0.
- Под Leaflet лежит синхронизированная карта Яндекса (JS API 3.0) без собственных элементов управления
  и со встроенной тёмной темой.
- Переключатель «Схема · Минимум · Подробно». В «Минимуме» стилизация слоя (`YM_MINIMAL`) скрывает
  организации, транспорт Яндекса, адреса и разметку, приглушает здания и цвет — остаются улицы, вода, парки.
- Трассы маршрутов — реальные, из `data/routes.json`. Если данных нет, используются схематичные трассы.
- Если JS API 3.0 не загрузился (например, у ключа нет ограничения по HTTP Referer — для 3.0 оно обязательно),
  подключается запасной JS API 2.1. Там стилизации нет: «Минимум» обесцвечивает подложку и кладёт вуаль цвета фона,
  тёмная тема делается инверсией. Какая версия работает, видно в подсказке переключателя.
- Улица в карточке аварии определяется HTTP-геокодером Яндекса (тот же ключ).
- Время доезда резерва считается по расстоянию и средней скорости.

## Что внутри

- **Экран 1 — оперативная карта.** Состояние покоя: KPI в шапке, карта с маршрутами,
  автобусами и резервом, лента событий и список маршрутов.
- **Состояние аварии.** Наступает через 10 с или по кнопке «Поломка сейчас». Срабатывают
  баннер над картой, карточка в ленте, пульсация на карте, красный маршрут 10, счётчики и звук.
- **Экран 2 — окно замены.** Данные сломанного борта, ранжированный резерв с причинами
  и рисками, влияние на интервалы, кнопка «Назначить на маршрут». Затем статус выполнения
  и 10 секунд на отмену.
- **UX-логика.** Иконка книги в левом меню: User Flow, тайминг, цветовая система, логика рекомендаций.

Горячие клавиши: `Enter` — решить / назначить, `1–4` — выбор кандидата, `Esc` — закрыть, `/` — поиск.

## Сборка

Исходники — `src/index.src.html` (полная версия) и `src/lite.src.html` (упрощённая).
Команда `python3 build.py <leaflet.css> [fragment-index.html] [fragment-lite.html]`
встраивает CSS Leaflet и собирает `index.html` и `lite.html` (при необходимости — ещё и фрагменты для публикации артефактом).

### Упрощённая версия · lite.html

Тот же прототип без второстепенного:
- Карточки краткие: номер борта, время доезда, доступность и бейджи отклонений. Раскрывается выбранный резерв,
  выбранный маршрут, событие ленты по клику, «Подробнее» у сломанного борта и в окне автобуса на карте.
- Панели демо нет: поломка случается сама через 10 с, перезапуск — клавиша R.
- Легенда «Статус ТС» свёрнута в кнопку рядом с «Остановки» и «Резерв».
- Вид карты: «Схема» и «Карта» (Яндекс, только дороги и названия улиц).
- Без верхней панели: карта и правая колонка на всю высоту. Поиск — сверху по центру карты,
  показатели смены — плашкой снизу по центру карты, аватар с ФИО и должностью — в левой колонке (подсказка при наведении).
- Окно замены — шириной с правую колонку, карточки со шевроном «Подробнее».
- Разделы в левом меню: «Маршруты и расписания», «Подвижной состав», «Инциденты» (список с поиском и фильтрами + карточка)
  и «Аналитика» (регулярность по получасам, опоздания по маршрутам, инциденты и реакция, выход на линию).
- «Справка» (кнопка с книгой в левом меню, на телефоне — в профиле): статьи для диспетчера — замена автобуса по шагам,
  выбор резерва, цвета и статусы, карта, разделы, горячие клавиши, работа с телефона, частые вопросы. Заменила прежнюю «UX-логику».
- Мобильная версия (экраны до 900 px): таб-бар снизу (Карта, Маршруты, Состав, Инциденты, Аналитика, Профиль),
  события — шторкой над картой (свёрнута / половина / весь экран, авария раскрывает её сама),
  окно замены и разделы — во весь экран; тема, звук и справка — в листе профиля по нажатию на аватар.

## Данные маршрутов

Трассы и остановки взяты с bus62.ru: `tools/extract_bus62.py` разбирает HAR-записи сайта
(и сохранённые ответы `getRouteNodes`) в `data/routes.json`, сборка вшивает его в страницу.
Прототип берёт маршрут 10 и шесть маршрутов с наибольшим общим участком с ним.
Госномера и позиции реальных автобусов не сохраняются. Бортовые номера, водители, резерв
и отклонения от графика смоделированы.

```
python3 tools/extract_bus62.py data/routes.json bus62.ru.har "10=route10-484.json,route10-485.json"
```
