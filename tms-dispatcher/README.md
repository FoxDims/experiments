# SmartTransport — рабочее место диспетчера

Интерактивный прототип B2B-системы управления городским автобусным транспортом (Рязань).
Сценарий: поломка автобуса на маршруте № 10 и его замена резервным бортом.

## Как открыть

Откройте `index.html` в браузере: файл самодостаточный, Leaflet подгружается с cdnjs.
Если доступны тайлы CARTO / OpenStreetMap, становится активен переключатель подложки «OSM».
Без них используется собственная векторная схема города.

## Что внутри

- **Экран 1 — оперативная карта.** Состояние покоя: KPI в шапке, карта с маршрутами,
  автобусами и резервом, лента событий и список маршрутов.
- **Состояние аварии.** Наступает через 10 с или по кнопке «Поломка сейчас». Срабатывают
  баннер над картой, карточка в ленте, пульсация на карте, красный маршрут 10, счётчики и звук.
- **Экран 2 — окно замены.** Данные сломанного борта, ранжированный резерв с причинами
  и рисками, влияние на интервалы, кнопка «Назначить на маршрут». Затем статус выполнения
  и 10 секунд на отмену.
- **UX-логика.** Иконка книги в левом меню: User Flow, тайминг, цветовая система, логика рекомендаций.

Горячие клавиши: `Enter` — решить / назначить, `1–4` — выбор кандидата, `Esc` — закрыть, `/` — поиск.

## Сборка

Исходник — `src/index.src.html`. Команда `python3 build.py <leaflet.css> [fragment.html]`
встраивает CSS Leaflet и собирает `index.html` (при необходимости — ещё и фрагмент для публикации артефактом).

Трассы маршрутов и названия остановок правдоподобны, но не совпадают с bus62.ru один в один.
Движение смоделировано.
